# CI/CD Integration — GitHub Actions & Newman

Thư mục này lưu trữ cấu hình CI/CD workflow và các hình ảnh minh chứng trạng thái chạy Pass và Fail trên GitHub Actions.

## Thành phần:
* `newman-api-test.yml`: File cấu hình GitHub Actions workflow.
* `ci-pass.png`: Ảnh chụp màn hình khi toàn bộ test cases đều PASS.
* `ci-fail.png`: Ảnh chụp màn hình khi có test case FAIL (chủ đích kiểm thử assertion).
