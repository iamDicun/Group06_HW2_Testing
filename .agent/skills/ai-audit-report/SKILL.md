# AI Audit Export Skill

Extracts the current conversation session and writes two output files:

1. **`prompt_log.md`** — append-mode raw session log, every word verbatim
2. **`AI_audit.md`** — structured audit table for academic submission

---

## Critical Rules (read first)

- **Timezone**: All timestamps use Vietnam time (UTC+7). Compute: `UTC + 7h`. Format: `YYYY-MM-DD HH:MM` (24h clock, full date AND time — never date-only).
- **Agent name**: Never assume "Claude". Ask the user which AI tool/agent was used (e.g., Claude, ChatGPT, Gemini, Copilot, a custom agent name, etc.) if not already stated in the conversation. Use whatever name they give.
- **prompt_log.md**: Every single word of every turn must be written verbatim. No truncation, no summarising, no omission of any character. This is a legal/academic record.
- **AI_audit.md logic**:
  - If the file does **not** exist → create it with the declaration line + table header + rows.
  - If the file **already exists** → read the existing file, then append **only new rows** to the existing table. Do NOT add a new table header. Do NOT add the declaration line again.
- **AI_audit.md content**: The file contains exactly and only:
  1. The declaration line: `I use AI tools for the following tasks:`
  2. A blank line
  3. The Markdown table (header + separator + rows)
  Nothing else. No title, no extra sections, no footnotes, no "Generated by..." text.
- IMPORTANT: ONLY RECORD THE PROMPTS BEFORE THE AUDIT PROMPT (the prompt that asks to create the audit report).

## Step-by-Step Execution

### Step 1 — Gather Parameters

Before doing anything, determine:

| Parameter | How to get it |
|-----------|--------------|
| **Agent name** | YOUR MODEL (Gemini, Claude, etc.) |
| **Assignment name** | Scan conversation for mentions like "HW02", "Domain Testing", etc. If not found, ask once. |
| **Output folder** | Use subfolder if user specified one or else in root folder. |
| **Vietnam timestamp** | Run `date -u` in bash, then add 7 hours. Format as `YYYY-MM-DD HH:MM`. |

Do NOT ask for anything already evident from the conversation.

### Step 2 — Get Vietnam Time

Run this bash command to get the exact Vietnam timestamp:

```bash
date -u -d '+7 hours' '+%Y-%m-%d %H:%M' 2>/dev/null || python3 -c "
from datetime import datetime, timezone, timedelta
vn = datetime.now(timezone.utc) + timedelta(hours=7)
print(vn.strftime('%Y-%m-%d %H:%M'))
"
```

Store this value as `VN_TIMESTAMP`. Use it everywhere a timestamp is needed.

### Step 3 — Extract All Turns (verbatim)

Scan the **entire conversation** from the first message to the current one. For each turn record:

- **Role**: `User` or `Assistant`
- **Content**: The complete, exact, unmodified text of the message. Every word. Every punctuation mark. Every newline. Including code blocks, lists, tables — everything. **No truncation, no summarising.**

Include only human-visible turns. Skip internal tool calls (bash executions, file reads) unless their output was shown to the user as part of the response.

Number turns sequentially starting at 1. Each "turn" is one User message + one Assistant response = one numbered turn.

### Step 4 — Write `prompt_log.md`

**Check if file exists:**

**If NEW** — create with header then session block.
**If EXISTS** — append session block only (no header).

**File header** (first creation only):
```
# Prompt Log
Verbatim record of all AI sessions for academic audit purposes.
```

**Session block format** (always appended):
```
---
## Session | Agent: <AGENT_NAME> | Assignment: <ASSIGNMENT> | <VN_TIMESTAMP> (UTC+7)
---

### Turn 1

**[User]**
<complete verbatim user message — every single word>

**[Assistant]**
<complete verbatim assistant response — every single word>

### Turn 2

**[User]**
<complete verbatim user message>

**[Assistant]**
<complete verbatim assistant response>

(continue for all turns)
```

**CRITICAL**: Copy every character exactly. Do not paraphrase. Do not shorten. Do not write "[continued...]" or similar. If a message is long, write it all.

### Step 5 — Write `AI_audit.md`

**Table columns:**

| # | Agent | Date & Time (UTC+7) | Assignment | Your Prompt | AI Output (summary) | Verdict | Student Fix |
|---|-------|---------------------|------------|-------------|---------------------|---------|-------------|

**Column rules:**
- **#**: Turn number (integer, starts at 1)
- **Agent**: The AI tool/agent name provided by user (e.g., `Claude (claude.ai)`, `ChatGPT`, `Gemini`, custom agent name)
- **Date & Time (UTC+7)**: Full `YYYY-MM-DD HH:MM` — must include both date and time. Never date alone.
- **Assignment**: Assignment name (e.g., `HW02 – Domain Testing`)
- **Your Prompt**: Exact user prompt. If over 150 chars, truncate at 150 chars and append `…`. Escape any pipe characters (`|` → `\|`) inside cell content.
- **AI Output (summary)**: One concise sentence (past tense) summarising what the AI produced.
- **Verdict**: `___` — student fills in `VALID`, `INVALID`, or `INCOMPLETE`
- **Student Fix**: *(empty)* — student fills in

**Logic for writing the file:**

```
IF /mnt/user-data/outputs/AI_audit.md does NOT exist:
    Create the file with EXACTLY this content (nothing else):

    I use AI tools for the following tasks:

    | # | Agent | Date & Time (UTC+7) | Assignment | Your Prompt | AI Output (summary) | Verdict | Student Fix |
    |---|-------|---------------------|------------|-------------|---------------------|---------|-------------|
    | 1 | <agent> | <VN_TIMESTAMP> | <assignment> | <prompt…> | <summary> | ___ | |
    | 2 | ...

ELSE (file already exists):
    Read the file.
    Determine the last # used in the existing table.
    Append ONLY the new rows (continuing the # sequence) after the last existing row.
    Do NOT add another table header.
    Do NOT add the declaration line again.
    Do NOT add any section separator.
```

**One row per user turn.** Do not create rows for assistant-only content.

### Step 6 — Report to User

After both files are written, print:

```
Done.
- prompt_log.md: <N> turns written (verbatim), appended to /mnt/user-data/outputs/prompt_log.md
- AI_audit.md: <N> rows added to /mnt/user-data/outputs/AI_audit.md
  → Open AI_audit.md and fill in the Verdict and Student Fix columns before submitting.
```

## Edge Cases

| Situation | Handling |
|-----------|----------|
| Pipe character `\|` inside a cell | Escape as `\|` in Markdown table |
| Code blocks in user prompt | Include verbatim in prompt_log; in audit table describe as: `[Code block] <one-line description>` |
| User prompt > 150 chars | Truncate at 150 chars + `…` in audit table only; full text in prompt_log |
| No assignment name in conversation | Use `(unspecified)` and note it in Step 6 report |
| User ran skill multiple times in one session | Each run appends its own session block to prompt_log; appends new rows to audit table |
| AI_audit.md exists but has no table yet (edge case) | Treat as NEW — write full header + rows |
