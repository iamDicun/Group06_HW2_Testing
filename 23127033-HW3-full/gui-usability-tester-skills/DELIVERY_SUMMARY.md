- **5 standard scenarios**: Onboarding, Navigation, Forms, Errors, Accessibility
- **Step-by-step format** with expected results
- **Time tracking** (per step & total)
- **Evidence collection** (screenshots, videos)
- **User satisfaction** metrics (1-5 rating)
- **YAML format** for flexibility

- **10 standardized questions** (WCAG-aligned)
- **1-5 Likert scale** responses
- **Automatic score calculation**: (Total × 2.5) = 0-100
- **Result interpretation**: Unacceptable → Excellent
- **Multi-user support**: 5+ respondents
- **Group analysis**: Average + trend

### ✅ PHASE 4: Bug Classification
- **4 severity levels**: 
  - 🔴 **BLOCKER** (24-48h SLA)
  - 🟠 **MAJOR** (3-5 day SLA)
  - 🟡 **MINOR** (2-3 week SLA)
  - ⚪ **COSMETIC** (optional/next sprint)
- **WCAG mapping**: IA-01 to IA-04 cross-reference
- **Impact analysis**: Users affected, business impact
- **Recommendation field**: How to fix

### ✅ PHASE 5: Watermark Automation
- **Batch PNG processing** (recursive directory scan)
- **Email + Name watermark** at bottom-left
- **Semi-transparent background** for visibility
- **Original backup creation** (.bak files)
- **Customizable**: Font size, color, position
- **Cross-platform**: Windows, macOS, Linux

### ✅ PHASE 6: GitHub Integration

- **Image URL conversion** to GitHub raw URLs
- **Severity-based labels**: blocker, major, minor

- **Duplicate detection** (skip existing issues)
- **Comprehensive logging** of sync operations
