# [BUG][Quản Trị Admin] Lưu cập nhật một sản phẩm làm đổi tên toàn bộ sản phẩm trong danh sách hiển thị

GitHub Issue: https://github.com/iamDicun/Group06_HW2_Testing/issues/118

## Test Case Phát Hiện
TC-IA04-012

## Yêu Cầu Liên Quan
FR-15

## Mức Độ / Độ Ưu Tiên
Major / P1

## Môi Trường
- Trình duyệt: Google Chrome / Firefox / Safari Mobile
- Hệ điều hành: Windows / iOS
- URL: `http://localhost:5174/` (Admin Panel)
- Build/Commit: HEAD

## Các Bước Tái Hiện
1. Đăng nhập tài khoản admin tại `http://localhost:5173/login`.
2. Truy cập trang quản trị Admin tại `http://localhost:5174/`.
3. Nhấp chọn menu "Sản phẩm", tìm một sản phẩm và bấm "Sửa".
4. Thay đổi trường "Tên sản phẩm" và nhấn "Lưu".
5. Quay lại danh sách sản phẩm và quan sát tên của tất cả sản phẩm khác.

## Kết Quả Mong Đợi
Hệ thống chỉ cập nhật thay đổi tên cho sản phẩm được chọn sửa đổi. các sản phẩm khác phải giữ nguyên tên cũ.

## Kết Quả Thực Tế
Sau khi lưu, toàn bộ sản phẩm trong cửa hàng đều bị ghi đè thành tên của sản phẩm vừa sửa đổi. Nguyên nhân do câu lệnh SQL UPDATE ở backend thiếu điều kiện ràng buộc `WHERE id = ?`.
