# Bảng Test Cases — API `/api/products/:id`

## Chú thích phân loại

| Ký hiệu | Ý nghĩa |
|---|---|
| **DP** (Domain Partitions) | Phân vùng tương đương & kiểm tra giá trị biên cho tham số `:id` (kiểu dữ liệu, phạm vi, định dạng). |
| **SEC** (Security) | Kiểm tra lỗ hổng bảo mật theo danh mục SEC-01 đến SEC-07 (SQL Injection, XSS, Path Traversal, Header Tampering). |
| **SV** (Schema Validation) | Kiểm tra tính đúng đắn về mặt cấu trúc JSON, kiểu dữ liệu từng trường đối chiếu trực tiếp với `api_specification.md`. |
| **ST** (State Transition & Resilience) | Kiểm tra sự thay đổi trạng thái của tài nguyên (Sản phẩm tồn tại → bị xóa) và khả năng chống chịu lỗi hệ thống (500/503). |
