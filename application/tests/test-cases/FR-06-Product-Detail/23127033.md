# GUI Checklist: FR-06 Product Detail View

## Requirement

- Requirement ID: `FR-06`
- Feature: Xem chi tiết sản phẩm
- Test type: GUI Testing, Black-box Testing
- Test account: `test@eshop.com` / `Test1234!`

## Preconditions

- Backend và frontend application đang chạy.
- Tester có thể truy cập web application bằng browser.
- Test account tồn tại và có thể dùng để login.
- Product list có ít nhất một product.

## Summary

Checklist này dùng cho Black-box GUI Testing của màn hình Product Detail View. Kết quả test hiện tại ghi nhận các phần hiển thị cơ bản như image, name, price, description, default quantity và responsive layout đang Pass. Các lỗi chính gồm thiếu category trên Product Detail, quantity input không validate `0`, số âm, decimal và empty value, click `Thêm vào giỏ hàng` lần đầu không có tác dụng, repeated add tạo nhiều dòng trùng product trong cart, và missing product message chưa thân thiện. Tester cần verify lại trên browser và cập nhật bug reference nếu tạo issue.
