# Bug Reports

Store black-box bug reports only after the bug is reproduced through the visible UI.

Current file:

- `BLACKBOX_BUG_DRAFTS.md`: candidate issues to verify. These are not final bug reports yet.

Each confirmed bug report must include:

- Found by Test Case ID.
- Related requirement.
- Severity and priority.
- Environment and build/commit.
- Steps to reproduce.
- Expected result.
- Actual result.
- Evidence link or file path.
- GitHub Issue link.

Use `templates/bug-report-template.md` and `.github/ISSUE_TEMPLATE/bug-report.yml` as the working formats.
