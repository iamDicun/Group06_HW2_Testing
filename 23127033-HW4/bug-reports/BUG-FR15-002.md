# Bug Report: BUG-FR15-002

**Mã Lỗi:** `BUG-FR15-002`  
**Tiêu Đề:** Hệ thống chấp nhận giá sản phẩm bằng 0 ₫ / Giá âm khi Admin tạo hoặc chỉnh sửa sản phẩm  
**Chức Năng:** `FR-15` Product Management (CRUD)  
**Module:** Web Admin (`PROD_MGMT`)  
**Mức Độ Nghiêm Trọng (Severity):** Major  
**Độ Ưu Tiên (Priority):** P1  
**Môi Trường:** Web Admin Portal (`http://localhost:5174`)  
**Trình Duyệt Bị Ảnh Hưởng:** Chromium, Firefox, WebKit  

---

## 1. Mô Tả Chi Tiết (Description)
Trang quản lý sản phẩm Admin Portal cho phép người dùng lưu sản phẩm có giá tiền bằng 0 ₫ (`price = 0`) hoặc giá âm (`price = -50000`). Hệ thống thiếu validation kiểm tra điều kiện ràng buộc `price > 0`.

---

## 2. Các Bước Tái Hiện Lỗi (Steps to Reproduce)
1. Đăng nhập Admin Portal tại `http://localhost:5174` bằng tài khoản Admin (`admin@example.com` / `Admin123!`).
2. Chọn tab "Sản phẩm".
3. Nhập tên sản phẩm: `Sản phẩm Giá 0đ`.
4. Nhập giá tiền: `0`.
5. Bấm nút "Lưu sản phẩm".

---

## 3. Kết Quả Thực Tế (Actual Result)
Sản phẩm với giá `0 ₫` được tạo thành công và hiển thị công khai trong bảng danh sách sản phẩm.

---

## 4. Kết Quả Kỳ Vọng (Expected Result)
Hệ thống báo lỗi validation: *"Giá sản phẩm phải lớn hơn 0 ₫!"* và từ chối gửi dữ liệu xuống Database.
