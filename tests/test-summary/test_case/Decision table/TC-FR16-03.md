# TC-FR16-03 | Rule: R2

- **Tiêu đề:** Từ chối import khi header CSV có tên cột sai
- **Tiền điều kiện:**
  - Đã đăng nhập bằng tài khoản Admin (`admin@eshop.com` / `Admin123!`)
  - Đang ở trang chức năng Import Sản phẩm từ CSV (Web Admin: `http://localhost:5174`)
- **Dữ liệu đầu vào:**
  - File: `test_tc16_03.csv` với nội dung:
    ```
    product_name,cost,description,imageUrl,category_id
    Sản phẩm A,100000,Mô tả A,http://img.com/a.jpg,1
    ```
  - *(Header dùng `product_name` thay vì `name`, `cost` thay vì `price`)*
- **Các bước thực hiện:**
  1. Truy cập trang Web Admin → chức năng Import Sản phẩm.
  2. Tải lên file `test_tc16_03.csv`.
  3. Nhấn nút **Import**.
- **Kết quả mong đợi:**
  - Hệ thống **từ chối**, không tiến hành import dữ liệu.
  - Hiển thị thông báo lỗi rõ ràng về header không hợp lệ, ví dụ: *"Header không đúng định dạng. Yêu cầu: `name,price,description,imageUrl,category_id`"*.
  - Không có sản phẩm nào được tạo mới trong CSDL.
  - Hệ thống **không** hiển thị báo cáo dòng lỗi/dòng thành công.
  *(Căn cứ FR-16: "Dòng đầu tiên là header: `name,price,description,imageUrl,category_id`")*
- **Loại kiểm thử:** Negative
