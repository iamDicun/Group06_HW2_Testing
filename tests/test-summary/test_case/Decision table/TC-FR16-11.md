# TC-FR16-11 | Rule: R7

- **Tiêu đề:** Import thành công với file CSV hợp lệ có trường chứa dấu phẩy được bọc nháy kép đúng RFC 4180
- **Tiền điều kiện:**
  - Đã đăng nhập bằng tài khoản Admin (`admin@eshop.com` / `Admin123!`)
  - Đang ở trang chức năng Import Sản phẩm từ CSV (Web Admin: `http://localhost:5174`)
  - Ghi nhớ số lượng sản phẩm hiện có trong CSDL (ví dụ: N sản phẩm)
  - Đã có ít nhất một danh mục tồn tại trong hệ thống (ví dụ: `category_id = 1`)
- **Dữ liệu đầu vào:**
  - File: `test_tc16_11.csv` với nội dung (lưu dưới dạng plain text):
    ```
    name,price,description,imageUrl,category_id
    "Áo thun cao cấp, sang trọng",299000,"Chất liệu cotton, thoáng mát",http://img.com/ao.jpg,1
    Quần shorts,199000,Quần shorts thể thao,http://img.com/shorts.jpg,1
    ```
  - *(Dòng 1: `name` và `description` chứa dấu phẩy bên trong, được bọc đúng chuẩn RFC 4180 bằng dấu nháy kép)*
  - *(Dòng 2: không có dấu phẩy trong nội dung trường — hợp lệ bình thường)*
- **Các bước thực hiện:**
  1. Truy cập trang Web Admin → chức năng Import Sản phẩm.
  2. Tải lên file `test_tc16_11.csv`.
  3. Nhấn nút **Import**.
  4. Kiểm tra CSDL: xác nhận số lượng sản phẩm tăng thêm 2 (= N + 2).
  5. Kiểm tra sản phẩm "Áo thun cao cấp, sang trọng": tên hiển thị đúng kể cả dấu phẩy, mô tả đúng.
- **Kết quả mong đợi:**
  - Hệ thống **import thành công** toàn bộ 2 sản phẩm, lưu đầy đủ vào CSDL.
  - Sản phẩm "Áo thun cao cấp, sang trọng" được lưu với **tên đầy đủ** bao gồm dấu phẩy (không bị cắt hoặc sai).
  - Hiển thị báo cáo: *"2 dòng thành công, 0 dòng lỗi"* (hoặc tương đương).
  - **Không** hiển thị thông báo lỗi.
  - Số lượng sản phẩm trong CSDL = N + 2.
  *(Căn cứ FR-16: "Hỗ trợ các trường có chứa dấu phẩy nếu được bọc trong dấu nháy kép (RFC 4180)")*
- **Loại kiểm thử:** Positive
