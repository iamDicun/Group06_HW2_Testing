# TC-FR16-01 | Rule: R1

- **Tiêu đề:** Từ chối import khi file tải lên không có đuôi `.csv`
- **Tiền điều kiện:**
  - Đã đăng nhập bằng tài khoản Admin (`admin@eshop.com` / `Admin123!`)
  - Đang ở trang chức năng Import Sản phẩm từ CSV (Web Admin: `http://localhost:5174`)
- **Dữ liệu đầu vào:**
  - File: `products.xlsx` (file Excel, nội dung hợp lệ nhưng sai định dạng)
- **Các bước thực hiện:**
  1. Truy cập trang Web Admin → chức năng Import Sản phẩm.
  2. Nhấn chọn file hoặc kéo thả file `products.xlsx` vào vùng upload.
  3. Nhấn nút **Import** (hoặc **Upload**).
- **Kết quả mong đợi:**
  - Hệ thống **từ chối ngay lập tức**, không tiến hành xử lý nội dung file.
  - Hiển thị thông báo lỗi rõ ràng, ví dụ: *"Định dạng file không hợp lệ. Vui lòng tải lên file có đuôi `.csv`"*.
  - Không có sản phẩm nào được tạo mới trong CSDL.
  - Hệ thống **không** hiển thị báo cáo dòng lỗi/dòng thành công.
  *(Căn cứ FR-16: "Đuôi file phải là `.csv`")*
- **Loại kiểm thử:** Negative
