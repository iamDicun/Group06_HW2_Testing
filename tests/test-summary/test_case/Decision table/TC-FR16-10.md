# TC-FR16-10 | Rule: R7

- **Tiêu đề:** Import thành công với file CSV hợp lệ hoàn toàn (không có trường chứa dấu phẩy)
- **Tiền điều kiện:**
  - Đã đăng nhập bằng tài khoản Admin (`admin@eshop.com` / `Admin123!`)
  - Đang ở trang chức năng Import Sản phẩm từ CSV (Web Admin: `http://localhost:5174`)
  - Ghi nhớ số lượng sản phẩm hiện có trong CSDL (ví dụ: N sản phẩm)
  - Đã có ít nhất một danh mục tồn tại trong hệ thống (ví dụ: `category_id = 1`)
- **Dữ liệu đầu vào:**
  - File: `test_tc16_10.csv` với nội dung:
    ```
    name,price,description,imageUrl,category_id
    Áo thun nam,150000,Áo thun cotton 100%,http://img.com/ao-thun.jpg,1
    Quần jeans,350000,Quần jeans slim fit,http://img.com/quan-jeans.jpg,1
    Giày sneaker,500000,Giày thể thao năng động,http://img.com/giay.jpg,1
    ```
  - *(3 dòng dữ liệu, tất cả hợp lệ, không có dấu phẩy trong nội dung các trường)*
- **Các bước thực hiện:**
  1. Truy cập trang Web Admin → chức năng Import Sản phẩm.
  2. Tải lên file `test_tc16_10.csv`.
  3. Nhấn nút **Import**.
  4. Kiểm tra CSDL: xác nhận số lượng sản phẩm tăng thêm 3 (= N + 3).
  5. Kiểm tra từng sản phẩm vừa import: tên, giá, mô tả, imageUrl, category_id đúng với dữ liệu file.
- **Kết quả mong đợi:**
  - Hệ thống **import thành công** toàn bộ 3 sản phẩm, lưu đầy đủ vào CSDL.
  - Hiển thị báo cáo: *"3 dòng thành công, 0 dòng lỗi"* (hoặc tương đương).
  - **Không** hiển thị thông báo lỗi.
  - Số lượng sản phẩm trong CSDL = N + 3.
  *(Căn cứ FR-16: "Admin có thể tải lên file CSV để import nhiều sản phẩm cùng lúc"; "Hệ thống hiển thị báo cáo rõ ràng: bao nhiêu dòng thành công")*
- **Loại kiểm thử:** Positive
