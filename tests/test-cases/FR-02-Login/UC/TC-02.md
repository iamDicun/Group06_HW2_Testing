**Kỹ thuật**: Use Case Testing
**Luồng tương ứng**: AF1

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Đang ở trang đăng nhập |
| **Steps** | 1. Nhập Email sai định dạng (vd. 'abc123', không có @). 2. Nhập Mật khẩu bất kỳ. 3. Bấm Đăng nhập |
| **Expected Result** | Trình duyệt chặn submit ngay tại client (HTML5 validation), hiển thị cảnh báo tại ô Email, không có request nào gửi lên server. Nên test thêm bằng cách gửi request trực tiếp tới API để xác nhận server-side cũng validate lại định dạng email |
