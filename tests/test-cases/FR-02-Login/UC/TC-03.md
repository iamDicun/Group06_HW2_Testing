# TC-03 — Use Case Test Case

**Nguồn**: UC-02 — Đăng nhập (EShop, FR-02)
**Kỹ thuật**: Use Case Testing
**Luồng tương ứng**: AF2

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản chưa từng sai hoặc mới sai 1 lần trước đó |
| **Steps** | 1. Nhập đúng định dạng Email nhưng email không tồn tại HOẶC Email đúng nhưng Mật khẩu sai. 2. Bấm Đăng nhập |
| **Expected Result** | Hệ thống tăng bộ đếm sai +1, trả về lỗi chung chung 'Email hoặc mật khẩu không đúng', không cấp JWT Token, tài khoản chưa bị khóa. Cần thực thi cả 2 biến thể input (email không tồn tại / mật khẩu sai) để xác nhận response giống hệt nhau |
