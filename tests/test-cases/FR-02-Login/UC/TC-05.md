# TC-05 — Use Case Test Case

**Nguồn**: UC-02 — Đăng nhập (EShop, FR-02)
**Kỹ thuật**: Use Case Testing
**Luồng tương ứng**: AF4

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản đang trong thời gian bị khóa tạm (chưa hết 30 giây) |
| **Steps** | 1. Nhập đúng Email. 2. Nhập ĐÚNG Mật khẩu. 3. Bấm Đăng nhập |
| **Expected Result** | Hệ thống TỪ CHỐI ngay, không xác thực mật khẩu, trả lỗi 'tài khoản đang tạm khóa', không cấp JWT Token dù mật khẩu đúng. Đây là test case quan trọng nhất về bảo mật - xác nhận hệ thống check trạng thái khóa TRƯỚC khi check mật khẩu |
