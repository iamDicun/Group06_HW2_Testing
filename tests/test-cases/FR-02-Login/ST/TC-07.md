# TC-07 — State Transition Test Case

**Nguồn**: FR-02 — Đăng nhập & Khóa tài khoản (EShop)
**Kỹ thuật**: State Transition Testing

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản ở S3 (đang bị khóa 30s) |
| **Steps** | Tiếp tục đăng nhập sai mật khẩu trong lúc đang khóa |
| **Expected Result** | Hệ thống từ chối, tài khoản vẫn ở S3, thời gian khóa KHÔNG bị gia hạn thêm, bộ đếm không tăng thêm |
| **Valid/Invalid** | Invalid |
| **Mức ưu tiên** | Trung bình |
| **Ghi chú** | Kiểm tra hệ thống không cộng dồn thời gian khóa khi tiếp tục sai |
