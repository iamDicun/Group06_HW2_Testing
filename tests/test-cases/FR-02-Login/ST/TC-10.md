# TC-10 — State Transition Test Case

**Nguồn**: FR-02 — Đăng nhập & Khóa tài khoản (EShop)
**Kỹ thuật**: State Transition Testing

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản ở S0 |
| **Steps** | Đăng nhập sai 2 lần liên tiếp (A1 roi A1 - 1-switch coverage) |
| **Expected Result** | Sau 2 lần sai, tài khoản ở S2 nhưng CHƯA bị khóa; nếu lần thử thứ 3 nhập đúng mật khẩu thì vẫn được chấp nhận bình thường (JWT trả về) |
| **Valid/Invalid** | Valid (1-switch, xác nhận boundary dưới ngưỡng khóa) |
| **Mức ưu tiên** | Cao |
| **Ghi chú** | Xác nhận hệ thống không khóa sớm trước khi đủ 3 lần sai liên tiếp |
