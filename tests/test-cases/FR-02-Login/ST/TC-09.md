# TC-09 — State Transition Test Case

**Nguồn**: FR-02 — Đăng nhập & Khóa tài khoản (EShop)
**Kỹ thuật**: State Transition Testing

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản ở S3 (đang bị khóa 30s) |
| **Steps** | Chờ đủ 30 giây cho hết thời gian khóa (sự kiện Timer A3) |
| **Expected Result** | Tài khoản tự động mở khóa, chuyển về S0, bộ đếm reset về 0 |
| **Valid/Invalid** | Valid |
| **Mức ưu tiên** | Cao |
| **Ghi chú** | Xác nhận cơ chế tự mở khóa hoạt động đúng thời gian quy định |
