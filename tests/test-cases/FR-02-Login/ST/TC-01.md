# TC-01 — State Transition Test Case

**Nguồn**: FR-02 — Đăng nhập & Khóa tài khoản (EShop)
**Kỹ thuật**: State Transition Testing

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản ở S0 (0 lần sai liên tiếp) |
| **Steps** | Đăng nhập sai mật khẩu |
| **Expected Result** | Bộ đếm tăng lên 1, tài khoản chuyển sang S1, hệ thống báo lỗi chung chung (không lộ nguyên nhân) |
| **Valid/Invalid** | Valid |
| **Mức ưu tiên** | Cao |
| **Ghi chú** | Luồng chính - lần sai đầu tiên |
