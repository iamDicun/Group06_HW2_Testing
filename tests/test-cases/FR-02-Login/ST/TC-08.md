# TC-08 — State Transition Test Case

**Nguồn**: FR-02 — Đăng nhập & Khóa tài khoản (EShop)
**Kỹ thuật**: State Transition Testing

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản ở S3 (đang bị khóa 30s) |
| **Steps** | Đăng nhập bằng ĐÚNG mật khẩu trong lúc đang khóa |
| **Expected Result** | Hệ thống vẫn TỪ CHỐI, KHÔNG trả JWT dù mật khẩu đúng, báo lỗi tài khoản đang tạm khóa |
| **Valid/Invalid** | Invalid (SECURITY-CRITICAL) |
| **Mức ưu tiên** | Cao nhất |
| **Ghi chú** | Lỗ hổng bảo mật nghiêm trọng nếu bị bypass: hệ thống phải kiểm tra trạng thái khóa TRƯỚC KHI kiểm tra mật khẩu |
