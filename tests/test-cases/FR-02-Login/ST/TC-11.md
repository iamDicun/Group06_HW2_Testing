# TC-11 — State Transition Test Case

**Nguồn**: FR-02 — Đăng nhập & Khóa tài khoản (EShop)
**Kỹ thuật**: State Transition Testing

| Trường | Nội dung |
|--------|----------|
| **Precondition** | Tài khoản ở S3 (đang bị khóa) |
| **Steps** | Chờ hết 30 giây (A3), sau đó đăng nhập bằng đúng mật khẩu (A2) - 1-switch coverage |
| **Expected Result** | Bước 1: tài khoản tự mở khóa, chuyển về S0. Bước 2: đăng nhập thành công ngay sau đó, trả về JWT Token |
| **Valid/Invalid** | Valid (1-switch, xác nhận luồng khôi phục hoàn chỉnh) |
| **Mức ưu tiên** | Cao |
| **Ghi chú** | Xác nhận toàn bộ chu trình khóa - mở khóa - đăng nhập lại hoạt động đúng, không còn dấu vết trạng thái khóa cũ |
